# 飞书自建应用配置指南

从零把一个飞书机器人接进群，并拿到发图所需的凭证。全程约 5 分钟，**免费**。

## 为什么必须用自建应用

飞书群里的「自定义机器人」webhook 只能发文字和卡片。发图片要求 `image_key`，而 `image_key` 只能通过开放平台的「上传图片」接口获得——那个接口需要应用凭证（`tenant_access_token`）。

所以：**想发二维码图片，必须有自建应用。**

---

## 第一步：创建应用

1. 打开 <https://open.feishu.cn/app>（需要企业/团队管理员或开发者权限）
2. **创建企业自建应用**
3. 填名称（如「发版机器人」）、描述，创建

## 第二步：添加机器人能力

左侧 **应用功能 → 添加应用能力** → 找到 **机器人** → 添加。

**只加这一个。** 网页应用、小程序、组件都不需要。

## 第三步：开通权限

左侧 **开发配置 → 权限管理**，搜索并开通：

| 权限标识 | 说明 | 必需 |
|---|---|---|
| `im:message` | 获取与发送单聊、群组消息 | ✅ |
| `im:message:send_as_bot` | 以应用的身份发消息 | ✅ |
| `im:resource` | 上传图片或文件资源 | ✅ |
| `im:chat:readonly` | 读取群信息（用于自动查 chat_id） | 建议 |

> 搜索时注意别开成同名的只读版本（如 `im:message:readonly`），那样只能读不能发。

## 第四步：发布版本 ⚠️

左侧 **版本管理与发布 → 创建版本**：

- 版本号：`1.0.0`
- 更新说明：随意
- 保存 → **申请发布**

管理员身份会直接通过；否则等管理员审批。

> **这一步最容易漏。** 权限变更只在发布新版本后生效。表现为：后台显示「已开通」，接口却一直返回 `99991672 Access denied`。

## 第五步：机器人进群

打开目标飞书群 → 右上角 **··· → 设置 → 群机器人 → 添加机器人** → 搜索应用名 → 添加。

只有进群后，应用才能往这个群发消息。

## 第六步：拿凭证

左侧 **凭证与基础信息**：

- **App ID**：`cli_` 开头
- **App Secret**：一串字符

填入 `release.config.json`：

```json
{
  "feishu": {
    "appId": "cli_xxxxxxxx",
    "appSecret": "xxxxxxxx",
    "chatId": "oc_xxxxxxxx"
  }
}
```

## 第七步：找 chat_id

```bash
node scripts/release.mjs --list-chats
```

输出：

```
机器人所在的群（1 个）：

  chat_id: oc_e3aa303819a72e0f213d12a4f14eb2db
  群名称 : 开发组
```

把 `chat_id` 填进配置。

## 第八步：自检

```bash
node scripts/release.mjs --check
```

期望输出（每项都通过）：

```
配置检查
  配置文件    : .../release.config.json
  项目目录    : .../my-project
  开发者工具  : E:\微信web开发者工具\cli.bat
  体验版二维码: .../.release/experience-qr.png
▸ 校验飞书应用凭证…
✓ app_id / app_secret 有效
✓ 目标群 chatId：oc_xxxx
▸ 校验上传图片权限…
✓ 图片上传权限正常（im:resource）
```

## 微信侧准备（仅小程序项目）

1. 安装微信开发者工具并**扫码登录**
2. **设置 → 安全设置 → 打开服务端口**（CLI 依赖它，不打开会一直卡住）
3. 项目根目录有 `project.config.json`，且 `miniprogramRoot` 指向真实小程序目录

### 体验版二维码怎么拿

前提：已经上传过代码，并且点过「选为体验版」。

公众平台 → **管理 → 版本管理** → 页面**上方**的「体验版」区域 → 二维码图片 → 右键另存为。

存到配置里 `project.experienceQr` 指向的位置，例如 `.release/experience-qr.png`。

> **体验版二维码约 7 天过期**，页面会写明「该二维码 X 月 X 日前有效」。脚本对超过 6 天的图会提醒重新获取。

### 体验成员

扫码的人必须在体验成员名单里，否则微信提示无权限。

公众平台 → **成员管理 → 体验成员** → 添加微信号。

---

## 需要发版时，上传和设体验版是两步

| 动作 | 谁做 | 说明 |
|---|---|---|
| 上传代码 | 脚本 `--upload` | 生成"开发版本" |
| 设为体验版 | **人工**，公众平台点一次 | 微信未开放接口 |

上传后不点「选为体验版」，体验版二维码指向的还是上一个版本。
